**Outcome:** Fully offline generative AI — no API keys, no latency overhead

**Stack:** `Python` `Scikit-Learn` `Pandas` `Matplotlib` `Jupyter`  
**Outcome:** High-recall fraud classifier robust to imbalanced data distribution
